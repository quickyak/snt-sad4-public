# Публичная информация СНТ «САД №4»

Статический сайт с открытыми документами СНТ «САД №4» (г. Казань).

## Что внутри
- Устав (действующая редакция 2022)
- Реквизиты, ЕГРЮЛ
- 217-ФЗ и ссылки на официальные источники
- Объявления от Правления (только свежие, до 90 дней)

## Сайт
https://quickyak.github.io/snt-sad4-public/

## Обновление
Источник — приватный репозиторий `snt-web`.
Генератор: `snt-web/scripts/build_public_site.py`.
